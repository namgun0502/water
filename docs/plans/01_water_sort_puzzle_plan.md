# 01. Water Sort Puzzle (색깔 물 옮기기 퍼즐 게임) 구현 계획서

## 1. 개요 및 목표
유리병 속 다양한 색상의 물을 옮겨 담아 각 병마다 한 가지 색으로 통일시키는 **Water Sort Puzzle** 웹/모바일 퍼즐 게임입니다.
남건님의 요구사항을 반영하여 감각적인 Modern Glassmorphism UI/UX 디자인, 수액/물 붓는 힐링 애니메이션, ASMR 사운드(Web Audio API 기반 효과음), 다양한 난이도(스테이지), 힌트/되돌리기/병 추가 기능 등을 갖춘 완성도 높은 프리미엄 앱으로 개발합니다.

---

## 2. 주요 기능 및 UI/UX 특징

### 🎨 디자인 및 시각적 효과 (Visual & Aesthetics)
- **Glassmorphism 유리병 렌더링**: 반투명 유리 질감, 빛 반사 하이라이트 및 부드러운 둥근 테두리 적용.
- **다이내믹 액체 애니메이션**: 물을 부을 때 곡선 주둥이 물줄기 애니메이션과 병 안 액체 층(Layer) 파동 애니메이션 적용.
- **힐링 파스텔/네온 컬러 파렛트**: 가시성이 뛰어나고 다채로운 8~12가지 커스텀 액체 색상.
- **승리 축하 효과**: 스테이지 클리어 시 화려한 폭죽(Confetti) 효과와 기분 좋은 효과음 연출.

### 🎧 사운드 및 ASMR (Sound System)
- Web Audio API를 활용한 물리 사운드 합성 (외부 파일 로딩 없이 정교한 물 따르는 소리, 병 터치음, 성공음 구현).
- 사운드 On/Off 토글 버튼 제공.

### 🎮 게임 플레이 핵심 규칙
1. **터치 조작**: 출처 병 선택 -> 대상 병 선택.
2. **이동 조건**: 
   - 대상 병의 맨 위 액체 색상과 이동할 액체 색상이 동일할 때.
   - 또는 대상 병이 완전히 비어 있을 때.
   - 대상 병에 여유 공간(기본 4칸 중 빈 공간)이 존재할 때.
3. **연속 이동**: 동일한 색상의 액체 층은 가능한 공간만큼 한번에 이동.
4. **승리 조건**: 모든 병이 비어있거나, 4칸이 모두 동일한 색상 1가지로 채워졌을 때.

### 🛠️ 편의 기능 (Game Features)
- **Undo (뒤로가기)**: 무제한 또는 횟수제 되돌리기.
- **Reset (재시작)**: 현재 스테이지 처음 상태로 리셋.
- **Add Bottle (병 추가)**: 보너스 빈 유리병 1개 추가 아이템.
- **Stage Manager (스테이지 시스템)**: Level 1부터 시작하여 단계별 난이도 상승 (색상 및 병 개수 증가).
- **자동 진행 상황 저장**: LocalStorage를 활용한 현재 진행 스테이지 및 설정 저장.

## 3. 기술 스택 및 구조
- **HTML5 & CSS3**: Flexbox/Grid, CSS Variables, Glassmorphic 3D styling, SVG/Canvas 효과.
- **Vanilla JavaScript (ES6+)**: 모듈화된 객체지향/이벤트 기반 설계.
- **Web Audio API**: 자체 생성 물리 음향 (물소리, 클릭소리, 클리어 팡파르).

## 5. 단계별 실행 계획 (Step-by-Step)

1. **Step 1: 문서화 및 승인 (현재 단계)**
   - `docs/plans/01_water_sort_puzzle_plan.md` 생성 및 사용자 승인 대기.
2. **Step 2: 핵심 퍼즐 데이터 구조 & UI 기초 구축**
   - HTML 구조 레이아웃 작성 (상단 헤더, 컨트롤 버튼, 병 배치 영역).
   - CSS Glassmorphism 유리병 스타일 구현.
3. **Step 3: 물 옮기기 인터랙션 & 퍼즐 알고리즘 구현**
   - 병 터치 및 물 이동 검증 로직.
   - 물 옮기는 곡선 애니메이션 및 레이어 업데이트.
4. **Step 4: Web Audio ASMR 음향 & 승리 축하 효과 연출**
   - 합성 물소리(Pouring sound) 및 성공 팡파르 연출.
   - 스테이지 생성기 및 진행 상황 저장 기능.
5. **Step 5: 검증 및 최종 완성**
   - 모바일 터치 및 반응형 웹 최종 검증.
